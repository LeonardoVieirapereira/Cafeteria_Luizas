DOCUMENTAÇÃO DO PROJETO ESCOLAR / ACADÊMICO

TITULO DO PROJETO: Pixel & Brew - Cafeteria Gamer
DISCIPLINA / CURSO: Desenvolvimento Web / Design
ALUNOS / AUTORES: Grupo de Projetos Integrados
PROFESSOR / ORIENTADOR: Docente da Disciplina

OBJETIVOS DO TRABALHO:

  • Criar um plano conceitual e website funcional para um estabelecimento híbrido (Cafeteria + Lan House).
  • Desenvolver uma interface responsiva focada no público jovem/gamer com estética Dark Neon.
  • Implementar seções interativas: menu filtrável, simulação de reservas e calendário de eventos.
  • Demonstrar a aplicação prática das tecnologias HTML, CSS (Tailwind) e JavaScript.

REQUISITOS TÉCNICOS ATENDIDOS:

Layout Responsivo Vetor SVG Customizado Filtros Dinâmicos em JS Dark Mode Theme
