Objetivos:

  • Apresentar o conceito de um estabelecimento híbrido: cafeteria e arena gamer.
  • Construir uma interface responsiva com identidade visual Dark Neon.
  • Implementar filtro de cardápio, menu mobile, efeitos visuais e simulação de reserva.
  • Demonstrar HTML, CSS e JavaScript em um projeto interativo.

Tecnologias: HTML5, CSS3, JavaScript, SVG/CSS 3D e bibliotecas externas opcionais para fontes e ícones.
